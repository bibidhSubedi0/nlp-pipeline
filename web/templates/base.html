Important Notice — Read Before Using

Deployment Limitations (Render Free Tier)

  • This demo is hosted on Render.com free tier which has 512MB RAM and limited storage
  • Large HuggingFace models (500MB+) will NOT work on this deployment due to memory/storage constraints
  • Only lightweight models (<200MB) are supported on the free tier
  • For full HuggingFace model support, run locally

Working HuggingFace Module Example

The Multilingual Sentiment Analyzer works on this deployment:

nlptown/bert-base-multilingual-uncased-sentiment ~110MB | Works on free tier

To enable: Go to Modules → Register with manifest → Go to Config → Enable it

Which HuggingFace Models Can You Plug In?

Not every HuggingFace model works with this pipeline. The plugin system uses the transformers pipeline API, so compatibility depends on the task type and the model file format.

  • WORK — classification tasks: text-classification, sentiment-analysis, zero-shot-classification. These return a label + score, which the adapter reads directly.
  • PARTIAL — token classification (NER): ner / token-classification. The full entity list is captured in the output, but the headline label is not derived (always shown as neutral).
  • DOES NOT WORK — generation / text2text: translation, summarization, text-generation, text2text-generation. These return generated_text, not label/score, so the result is dropped.
  • Must be a standard transformers model with a valid config.json (contains a model_type). Raw checkpoints (e.g. .pt / .bin files without config, custom training artifacts) fail to load with Unrecognized model.
  • For sentiment coloring in this UI, the model's labels should be positive / negative / neutral.
